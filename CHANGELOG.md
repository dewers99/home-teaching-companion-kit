# Changelog

## [1.0.0] — 2026-09-28

Initial release of the Home Teaching Companion Kit.

- **State-ambiguous core.** The core no longer names or privileges any state, country, or territory: `templates/ohio-notification-checklist.template.md` became the state-neutral `templates/notification-checklist.template.md` (every state-specific line is filled from the active state module); AGENT.md's skill router lists state modules alphabetically with no state first; the outdated-law example and feedback-form category are state-neutral. Comparison tables (notification tiers, testing, records, compulsory ages, watch-outs index) are kept in the core as a documented deliberate design decision with a maintenance rule (module changes update the core tables in the same pass). Subject appendices keep Ohio's standards as a labeled worked example (that's what they were verified against) with a standard note in each: typical U.S. scope and sequence for planning, while the family's state module is the binding document for requirements. Ohio legal facts in the appendices (compulsory age, College Credit Plus) appear only as labeled "Example (Ohio)" illustrations that defer to the state module — never stated as general rules.
- **Calendar-quarter compliance checks.** Quarterly mode now runs on calendar quarters — January, April, July, October — instead of three months from install date. First check is due at the first quarter boundary after setup. (Law moves on legislative calendars, so this also lines up better with real-world change cycles.)
- INSTALL.md's kit description corrected (it still described the original six-skill Ohio-only layout; now sixteen skills, seven templates, nineteen appendices across nine states).
- **Transcript/log exception kept, now state-adaptable** (Daniel's call): the high-school transcript exception stays — learning logs remain grade-free, transcripts may carry grades and credits, never blurred — but the transcript must now be built against the active state module's rules, recommendations, or requirements first (scholarship paperwork, superintendent letters, diploma rules).
- **Feedback form standardization (cross-kit).** Adopted the shared standard: tenure-neutral summary ("A quick report card for your teaching assistant…"), 7 questions in the standard order, hints on every open-text question, standardized thank-you. Companion behavior (AGENT.md): the form is offered once two weeks after install and any time the user mentions feedback. Spec rewritten in the kit's fun-but-professional tone.
- **Tally forms live.** Feedback form: https://tally.so/r/D4QLKp — state/territory/country request form: https://tally.so/r/Y5824z. README, INSTALL, AGENT, and both specs updated; the companion now shares the real links instead of skipping the offers silently.
- **State/territory/country request mechanism.** New `state-request-form-spec.md` (separate Tally form from the feedback form): one required question (which place), optional email for a notification when it's added, optional open text for anything the family can share about the homeschool requirements where they live (treated as unverified leads). The companion offers it whenever the family's state, country, or territory isn't covered — at intake and on compliance questions. Wired into README, INSTALL, AGENT.md, the intake skill, and the compliance core.
