# Progress tracking skill

**Version:** 1.0.1

## When to use

Use this module when the parent wants to record what was covered in a day or week, note observations about how learning is going, or review how one of their children is doing over time. It is the kit's simple learning log: brief entries, kept per child, reviewed on request. It is not a gradebook, not a report card, and not an assessment system — just a running record the parent controls.

## Procedure

1. Confirm which child the entry is for, and start a separate log thread per child if one does not exist yet. Never mix two children's entries in one log; if the parent mentions a second child mid-entry, open that child's log and record the entry there instead.
2. Capture the entry with these fields, kept to a few lines each:
   - Date
   - Subjects or activities covered
   - What went well
   - What was hard or got skipped
   - Observations — light touch only: interests that surfaced, mood, energy, things the child asked about
   - Next steps (what to revisit, try next, or prepare)
   Brief beats thorough. A two-line Friday note is worth more than a blank page; say that out loud when a parent stalls.
3. Offer a rhythm but never nag. Suggest a simple weekly note (e.g., five minutes on Friday) or a per-session jotting, whichever fits the family's pace. If the parent skips weeks, mention nothing about it — just pick up where they are.
4. On request, summarize one child's recent entries into a progress snapshot: what's been covered, emerging strengths, and things to revisit. Read the child's log first, then answer in chat. Keep snapshots plain and descriptive — no grades, no levels, no verdicts about whether the child is "on track."

## Output

Filled `templates/progress-log.template.md` entries — either the parent's words pasted into the template, or a template-shaped recap the parent approves. Snapshots are given in chat on request, referencing dates and entries so the parent can verify them. If the AI tool cannot save files, say so plainly and give the parent the filled template as copy-paste text instead of pretending it was stored.

## Boundaries

- This is not an assessment or grading system and is never presented as one. Do not assign grades, levels, or readiness labels.
- **High school exception:** for 9th–12th grade, the parent may keep a separate transcript with course grades and credits (see `reference/9-12-subjects.md`) — transcripts are how the outside world reads high school work. The learning log itself stays grade-free; the transcript is a different document with a different purpose. Never blur the two. Adapt the transcript to the family's state: check the active state compliance module first for state-specific rules, recommendations, or requirements on transcripts, diplomas, graduation documentation, or scholarship paperwork (they exist — e.g., district-processed scholarship forms, superintendent letters for state university systems), and build the transcript to satisfy those alongside the general guidance.
- Does not diagnose learning disabilities or developmental conditions. If the parent raises concerns about how a child is learning, acknowledge it warmly and suggest talking with a pediatrician or qualified evaluator — a log is not a diagnosis.
- Logs belong to the parent: they can read, correct, or delete entries at any time. Never rewrite or "clean up" an entry silently; if something needs fixing, ask first and show the change.
- Never share, compare, or rank one child's log against a sibling's. Each child is tracked separately, period.
