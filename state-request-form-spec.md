# State/territory request form spec — Home Teaching Companion Kit v1.0.0

*Live form: https://tally.so/r/Y5824z — built by Daniel on Tally from this spec — a separate form from the feedback form. Short: one required question, the rest optional.*

*Spec note for Daniel: responses to Q2 are unverified leads, not facts. Every claim gets checked against official sources before it goes into a module — same as the kit's own research.*

## Form title

"State/Territory Request for the Home Teaching Companion"

## Form description (summary)

"Don't see your state, territory, or country covered yet? Request it here. Requests are counted and the most-requested places get built first — no timeline promised. This form is anonymous with the exception of the optional email field, which is only used to notify you when your place is added."

## Q1 (required) — Which place?

Which state, territory, or country should be added?

- Short text, required.

## Q2 — What do you know? (open text, optional)

What do you know about homeschooling requirements where you live?

- Long text, optional.
- Hint: "Links to any official sources are extremely helpful."

## Q3 — Notify me? (multiple choice, optional)

Want to be notified when it's added?

- A. Yes, please
- B. No, thank you
- Conditional: if A, show hint "Leave your email." and an email address field.

## Closing screen

"Thank you — your request has been received and will be personally reviewed by Daniel."
